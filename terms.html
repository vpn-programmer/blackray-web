Пользовательское соглашение (Публичная оферта)

Настоящий документ является публичной офертой (далее — «Соглашение») сервиса BlackRay Cloud (далее — «Провайдер») и содержит все существенные условия предоставления услуг по аренде вычислительных мощностей.

1. Термины и определения

1.1. «Провайдер» — сервис BlackRay Cloud, предоставляющий услуги по аренде виртуальных вычислительных мощностей (IaaS) и обеспечению удалённого доступа к сетевой инфраструктуре.

1.2. «Пользователь» — дееспособное физическое лицо, осуществившее Акцепт настоящей Оферты.

1.3. «Удалённый доступ» — технология предоставления Пользователю выделенного канала связи для управления арендованными серверными ресурсами.

1.4. «Бот» — автоматизированный аппаратно-программный интерфейс Провайдера в мессенджере Telegram, предназначенный для регистрации, управления биллингом и получения реквизитов доступа.

1.5. «Реквизиты доступа» — уникальный набор авторизационных данных и сетевых настроек, генерируемый индивидуально для подключения оборудования Пользователя к инфраструктуре Провайдера.

2. Общие положения и порядок Акцепта

2.1. Безусловным принятием (Акцептом) условий настоящей Оферты считается запуск Бота, пополнение лицевого счёта или фактическое начало использования Реквизитов доступа для подключения к инфраструктуре Провайдера.

2.2. Сервис является инструментом для удалённой работы, тестирования IT-продуктов и развёртывания пользовательских приложений. Провайдер предоставляет только сетевую и аппаратную инфраструктуру. Ответственность за цель использования вычислительных мощностей лежит исключительно на Пользователе.

3. Права и обязанности сторон

3.1. Пользователь обязуется:

3.1.1. Использовать вычислительные мощности в строгом соответствии с применимым законодательством.

3.1.2. Не создавать избыточную нагрузку на магистральные каналы связи Провайдера, в том числе путём использования протоколов непрерывного массового файлообмена (P2P/BitTorrent) на вычислительных узлах, не предназначенных для хранения больших объёмов данных.

3.1.3. Не использовать инфраструктуру Провайдера для осуществления вредоносной деятельности:

  • Организация DDoS-атак, сканирование портов, брутфорс;
  • Распространение вредоносного ПО;
  • Осуществление спам-рассылок любого типа;
  • Фишинг, мошенничество и несанкционированный доступ к чужим данным.

3.1.4. Не передавать свои Реквизиты доступа третьим лицам. Услуга предоставляется для индивидуального использования. При фиксации одновременных подключений с использованием одних авторизационных данных Провайдер оставляет за собой право аннулировать скомпрометированные реквизиты.

3.2. Провайдер обязуется и имеет право:

3.2.1. Обеспечивать бесперебойную работу аппаратной части серверов и сетевой доступности.

3.2.2. Приостановить или прекратить оказание услуг (заблокировать аккаунт) без возмещения средств в случае нарушения Пользователем пунктов 3.1.2 — 3.1.4.

4. Стоимость услуг и порядок расчётов

4.1. Доступ к услугам Провайдера предоставляется по авансовой системе расчётов.

4.2. Списание средств с лицевого счёта Пользователя происходит ежедневно (посуточно) за каждую активную выделенную ноду (устройство), добавленную в интерфейсе Бота.

4.3. Базовая стоимость аренды вычислительных мощностей для 1 (одного) подключения составляет 149 рублей за 30 (тридцать) календарных дней.

4.4. При отрицательном или нулевом балансе Провайдер автоматически приостанавливает обслуживание инфраструктуры Пользователя до момента пополнения счёта.

4.5. Для остановки тарификации Пользователь обязан самостоятельно удалить неиспользуемую ноду в интерфейсе Бота.

5. Ограничение ответственности и возврат средств

5.1. Услуги Провайдера предоставляются на условиях «КАК ЕСТЬ» (AS IS). Провайдер не несёт ответственности за любой прямой или косвенный ущерб, возникший в результате использования сервиса.

5.2. Возврат неизрасходованных средств производится в случае технической аварии на аппаратной стороне Провайдера, продолжающейся более 72 часов подряд.

5.3. Возврат не осуществляется при блокировке за нарушение правил сервиса (п. 3.1), а также при индивидуальных сетевых ограничениях на стороне локального интернет-провайдера Пользователя.

6.1. Провайдер запрашивает исключительно минимальный набор технических данных, необходимых для оказания услуг: Telegram ID (для авторизации в биллинговой системе) и агрегированную статистику объёма переданных данных (для учёта тарификации).

6.2. Провайдер не имеет технического доступа к информации, передаваемой или хранимой Пользователем на арендованных вычислительных мощностях. Логирование действий пользователей на уровне операционной системы серверов отключено в целях оптимизации производительности оборудования.

6.3. Провайдер не осуществляет передачу технических данных третьим лицам, за исключением случаев получения официального мотивированного запроса от правоохранительных органов в рамках действующего законодательства юрисдикции расположения серверов.
